# Contributing to Attribution

## Managing the default branch name for repositories in your organization

You can set the default branch name for repositories that members create in your organization on GitHub.

### About management of the default branch name

When a member of your organization creates a new repository in your organization, the repository contains one branch, which is the default branch. You can change the name that GitHub uses for the default branch in new repositories that members of your organization create. For more information about the default branch, see [About branches](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-branches).

You can change the default branch for an existing repository. For more information, see [Changing the default branch](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-branches-in-your-repository/changing-the-default-branch).

If an enterprise owner has enforced a policy for the default branch name for your enterprise, you cannot set a default branch name for your organization. Instead, you can change the default branch for individual repositories. For more information, see [Enforcing repository management policies in your enterprise](https://docs.github.com/en/admin/policies/enforcing-policies-for-your-enterprise/enforcing-repository-management-policies-in-your-enterprise) and [Changing the default branch](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-branches-in-your-repository/changing-the-default-branch).

### Setting the default branch name

1. In the upper-right corner of GitHub, click your profile picture, then click **Organizations**.
2. Select an organization by clicking on it.
3. Under your organization name, click **Settings**. If you cannot see the "Settings" tab, select the dropdown menu, then click **Settings**.
4. In the "Code, planning, and automation" section of the sidebar, select **Repository**, then click **Repository defaults**.
5. Under "Repository default branch", click **Change default branch name now**.
6. In the text field, type the default name that you would like to use for new branches.
7. Click **Update**.
